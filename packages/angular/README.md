# @brandsync/angular

Angular wrappers for the Brandsync design system web components (`@brandsync/wc`), generated by
`@stencil/angular-output-target`. Components are exposed as Angular **standalone components**, so
they can be imported directly into other standalone components or NgModules without an
intermediate module.

## Install

```sh
npm install @brandsync/angular @brandsync/wc
```

`@angular/core` (`^19.0.0`) is a peer dependency and must already be present in your app.

## Usage

```ts
import { Component } from '@angular/core';
import { BsComposer } from '@brandsync/angular';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [BsComposer],
  template: `<bs-composer></bs-composer>`,
})
export class AppComponent {}
```

## Required: load the design token stylesheet

Every component's shadow-DOM CSS is written against `--bs-*` custom properties that this package does not inject on its own. Without them, components render with no visible border/background and collapse to near-zero size (no console error — `var(--bs-*)` with no fallback just resolves to its CSS initial value). This is easy to miss in an Angular app that already has its *own* differently-named design tokens (e.g. `--surface-base`) mapped onto its own stylesheets — that app-level token file does not satisfy this, since the shadow-DOM CSS only resolves `--bs-*`-prefixed names.

Add the vendored token stylesheet to your app's global styles, e.g. in `angular.json`:

```json
"styles": [
  "node_modules/@brandsync/wc/dist/brandsync-wc/brandsync-wc.css",
  "src/styles.css"
]
```

or via a plain `@import` in `src/styles.css`:

```css
@import '@brandsync/wc/dist/brandsync-wc/brandsync-wc.css';
```

Note: the vendored stylesheet currently contains a handful of malformed token declarations from an upstream `brandsync-tokens` export step (e.g. `--bs-5-brand-colors-jade-brand-700: {Brand Colors.teal.700};`), which Angular's build may warn about. These are pre-existing in the vendored dependency and harmless — they don't affect any token this library actually uses.

See `@brandsync/wc`'s own README ("Design tokens — required, not optional") for the full explanation.
