## Getting started

```bash
npm install @brandsync/angular @brandsync/wc
```

```ts
import { BsButton } from '@brandsync/angular';
// Every bs-* component's styling is written entirely against --bs-* design tokens, and this
// package doesn't inject them itself -- this import is what actually makes them visible.
import '@brandsync/wc/dist/brandsync-wc/brandsync-wc.css';

@Component({
  standalone: true,
  imports: [BsButton],
  template: `<bs-button variant="primary">Book room</bs-button>`,
})
export class ExampleComponent {}
```

> **Don't skip the CSS import.** Skipping it is the #1 cause of a `bs-*` component rendering with
> no visible border/background and near-zero size — with no console error to point you at why.
> The tokens also define `Roboto` as the typeface by name, but don't load the font file itself —
> that's the consuming app's job too (a `<link>` to Google Fonts, `next/font/google`, etc.).
